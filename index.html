📖 New to RL? Plain-English glossary
Agent
The learner that makes choices.
Environment
Everything the agent interacts with. It reacts to actions.
State (s)
What the agent sees right now.
Action (a)
A choice the agent can make in a state.
Reward (r)
A score after an action. Positive is good, negative is bad.
Policy
The agent's strategy: which action to take in which state.
Episode
One full attempt, from start to finish.
Q(s,a)
How good action a is in state s, measured in expected total reward.
α
Learning rate: how much one new experience changes an old estimate.
γ
Discount: how much future rewards count compared with immediate ones.
ε
Exploration: the chance of trying a random action instead of the best known one.
TD error δ
The surprise: what actually happened minus what the agent expected.
Regret
Reward lost by not always choosing the best option.
